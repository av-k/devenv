# configurable here.

# To see what was refused, read the filter's counters from the host, in the
# project directory of the running session:
#   docker exec -u root "$(docker ps -q --filter "label=devenv=$PWD")" \
#       iptables -L OUTPUT -v -n --line-numbers
# (ip6tables for IPv6). Denied attempts also hit a LOG rule with the prefix
# "devenv-deny:" ("devenv-deny6:" for IPv6), but dmesg and journalctl show
# nothing by default: the rule fires in the container's network namespace,
# whose log the kernel discards unless net.netfilter.nf_log_all_netns=1.
# See "Seeing what the filter rejected" in README.md.
